# Starisc-2

В этой задаче тебе нужно:

В статическом блоке считать с консоли А и В — две переменные с типом int.
Обработать IOException в блоке catch.
Закрыть поток ввода методом close().


Псевдокод:

```
АЛГОРИТМ Solution
    ОПИСАНИЕ: Программа считывает два целых числа и выводит минимальное из них

    ГЛОБАЛЬНЫЕ ПЕРЕМЕННЫЕ:
        ЦЕЛОЕ A = 0
        ЦЕЛОЕ B = 0
        ЦЕЛОЕ MIN = результат вызова min(A, B)

    СТАТИЧЕСКИЙ БЛОК ИНИЦИАЛИЗАЦИИ:
        НАЧАЛО
            СОЗДАТЬ BufferedReader reader для чтения из System.in
            
            ПОПЫТАТЬСЯ:
                A = ПРЕОБРАЗОВАТЬ_В_ЦЕЛОЕ(reader.прочитатьСтроку())
                B = ПРЕОБРАЗОВАТЬ_В_ЦЕЛОЕ(reader.прочитатьСтроку())
                reader.закрыть()
            ПЕРЕХВАТИТЬ IOException:
                ВЫВЕСТИ стек ошибки
        КОНЕЦ

    ФУНКЦИЯ main(аргументы):
        ВЫВЕСТИ MIN

    ФУНКЦИЯ min(ЦЕЛОЕ a, ЦЕЛОЕ b) ВОЗВРАЩАЕТ ЦЕЛОЕ:
        ЕСЛИ a < b ТО:
            ВЕРНУТЬ a
        ИНАЧЕ:
            ВЕРНУТЬ b
        КОНЕЦ_ЕСЛИ
```

Блок-схема алгоритма:

```
[НАЧАЛО]
    │
    ▼
[Статическая инициализация]
    │
    ▼
[Создать BufferedReader]
    │
    ▼
[Считать A] ──► [Считать B]
    │
    ▼
[Вычислить MIN = min(A, B)]
    │
    ▼
[main: вывести MIN]
    │
    ▼
[КОНЕЦ]
```

Пояснение к псевдокоду:

1. Статический блок выполняется один раз при загрузке класса
2. Программа ожидает ввода двух чисел с клавиатуры
3. После ввода чисел вычисляется минимальное значение
4. В методе main выводится результат
